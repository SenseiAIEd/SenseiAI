# Judges one-pager — Sensei Desk Fri (~90 s)

**Story:** Sensei is not Photomath. A student plants a classic vector mistake; Sensei stays quiet, then on Hint asks one Socratic question aimed at the first wrong step, then recognizes the fix on Check. Offline tutoring loop — Eyes + Brain — not vision Q&A.

**Plant:** ball launched 20 m/s at 60°. Student wrote `v_y = 20` (never resolved). Fix → `20 sin(60)` path ≈ **3.54 s**.

## What judges see (beats)

1. Phone overhead watching the page (arm if ready, else fixed DJI).
2. Planted sheet slides under camera → tap **Check** → Sensei flags the vector miss; does **not** dump 3.54 s.
3. Student taps **Hint** → one Socratic on components (“is all of that motion upward?”).
4. Student rewrites fix in large dark ink → tap **Check** → congrats / asks why sin; no false re-flag.
5. Stop. ~90 s. Backup take ready if live fails twice.

## Hard no’s (do not demo)

- No algebra as the primary Fri problem
- No voice-**in** tutoring (ASR off; taps only)
- No answer dump / spoon-feed / Photomath path
- No SYSTEM_PROMPT chase mid-demo
- No betting Fri on unproven arm — DJI fallback is fine
- No continuous “what do you see?” vision chat

**Polish (nice, not required):** short non-leaking TTS + phone screen after Hint/Check.
